## 1. Dataset Overview & Provenance

The model is trained and validated on a widely benchmarked, structured medical symptom dataset designed for supervised multi-class disease classification.

| Characteristic | Specification |
|---|---|
| **Origin / Publisher** | Kaushil268 (Kaggle) & Columbia University Medical Center / Medical Lexicon Archives |
| **Problem Type** | Multi-Class Supervised Classification (41 Target Classes) |
| **Input Modality** | Binary Symptom Indicators ($X_i \in \{0, 1\}$) |
| **Total Features** | 132 Distinct Clinical Symptoms |
| **Target Variable** | `prognosis` (Categorical String, 41 Diseases) |
| **Training Records** | 4,920 records (120 per disease class — balanced) |
| **Testing Records** | 42 records (Independent validation set) |

## 2. File Specifications & Preprocessing Pipeline

### 2.1 Raw Files
1. **`dataset/Training.csv`**
   - **Dimensions:** 4,920 rows × 134 columns.
   - **Artifact Column:** Contains an empty trailing column named `Unnamed: 133` generated by trailing commas in Kaggle's CSV export.
   - **Cleaning Action:** Automatically identified and stripped during data loading (`df.drop(columns=['Unnamed: 133'])`).
   - **Missing Values:** Zero missing values in the 132 symptom columns.
2. **`dataset/Testing.csv`**
   - **Dimensions:** 42 rows × 133 columns.
   - **Structure:** 132 symptoms + 1 `prognosis` target column.
   - **Cleanliness:** Zero missing values.

### 2.2 Data Preprocessing Routine
1. **Column Alignment Check:** Automated assertion that the 132 symptom names and ordering in `Testing.csv` match `Training.csv` identically.
2. **Feature Matrix Construction:**
   $$X = [s_1, s_2, \dots, s_{132}] \quad \text{where } s_j \in \{0, 1\}$$
3. **Target Vector:**
   $$y \in \{\text{"Fungal infection"}, \text{"Allergy"}, \dots, \text{"Impetigo"}\}$$

## 6. Model Input Feature Vector Construction

When an inference request arrives (e.g., `["itching", "skin_rash"]`):

1. **Zero Initialization:** A zero vector of shape $(1, 132)$ is initialized:
   $$\vec{v} = [0, 0, 0, \dots, 0]$$
2. **Feature Mapping:** The exact column index of each verified symptom in the saved metadata vocabulary is located.
3. **One-Hot Flagging:**
   $$\vec{v}[\text{index}("itching")] = 1, \quad \vec{v}[\text{index}("skin\_rash")] = 1$$
4. **DataFrame Conversion:** Passed to the Random Forest model with column headers intact to preserve feature identity and prevent silent misalignments.

## 7. Dataset Strengths & Academic Limitations

### Strengths
- **Balanced Class Distribution:** 120 samples per disease prevents class imbalance bias.
- **High Multi-Class Diversity:** 41 distinct diseases span major clinical disciplines.
- **Deterministic Evaluation:** Held-out 42-record test set allows consistent cross-algorithm comparisons.

### Academic Limitations
- **Binary Symptom Nature:** Does not capture symptom severity (e.g., mild vs. severe fever) or duration.
- **Synthetic Permutations:** Training records represent synthetic permutations of clinical co-occurrences.
- **Fixed Vocabulary:** Only 132 predefined keywords are recognized; natural language descriptions must be mapped to identifiers.
